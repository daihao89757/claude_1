# 🍅 番茄钟

一个单文件的番茄工作法计时器，零依赖、纯前端。

## 使用

直接双击 `index.html` 即可，或双击 `启动番茄钟.bat` 以无地址栏的独立窗口打开（依赖 Edge）。

## 功能

- **三种模式**：专注 25 分 / 短休 5 分 / 长休 15 分，时长都可在界面上直接改
- **自动循环**：每完成 4 个番茄自动进入长休，否则进入短休
- **环形进度条**：随倒计时收缩，颜色跟随模式变化
- **提醒**：结束时播放提示音（Web Audio 实时合成，无需音频文件），并弹出系统通知
- **设置记忆**：自定义时长通过 `localStorage` 保存在本地

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` | 开始 / 暂停 |
| `R` | 重置当前计时 |

## 说明

全部逻辑集中在 `index.html` 一个文件里，没有构建步骤、没有依赖，方便直接读源码或改样式。
