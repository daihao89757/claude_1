# claude_1

这是我的第一个 Git 仓库，用来熟悉 Git 与 GitHub 的基本工作流。

## 我在学什么

- 本地仓库与远程仓库的关系
- `add` → `commit` → `push` 三步流程
- 分支、提交历史这些概念到底是怎么回事

## 常用命令

```bash
git status               # 看当前状态
git add .                # 把改动放进暂存区
git commit -m "说明"      # 存档
git push                 # 推送到 GitHub
```
